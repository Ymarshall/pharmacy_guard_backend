## Convention

- Numérotation séquentielle `ADR-XXX`.
- Structure obligatoire : Titre, État, Contexte, Décision, Conséquences.
- Un ADR documente une décision **déjà implémentée** ou formellement retenur ; les hypothèses ouvertes restent hors périmètre.
